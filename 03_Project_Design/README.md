# Phase 3 – Project Design

## 3.1 Problem–Solution Fit

Traditional cricket performance management often uses manual records, which can be time-consuming and prone to errors.

CRICKSTATS addresses these problems by using Salesforce to provide:

- Accurate and efficient data entry
- Secure cloud storage
- Centralized player and match information
- Interactive dashboards
- Real-time reports
- Faster access to performance information

## 3.2 Proposed Solution

CRICKSTATS provides the following:

- Custom Objects – Player and Match Performance
- Master-Detail Relationships
- Roll-Up Summary Fields
- Lightning App
- Automated Flows
- Interactive Dashboards

### Key Features

- Centralized database
- Live statistics
- Secure access
- Scalable design
- Easy reporting

## 3.3 Solution Architecture

The CRICKSTATS architecture consists of four main layers:

### 1. Presentation Layer
Salesforce Lightning UI

### 2. Application Layer
Flows and application logic

### 3. Data Layer
Salesforce Objects

### 4. Analytics Layer
Reports and Dashboards
