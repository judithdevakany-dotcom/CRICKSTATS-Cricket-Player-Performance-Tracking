# Phase 1 – Brainstorming & Ideation

## Project Title
CRICKSTATS – Cricket Player Performance Tracking Application

## Project Idea
CRICKSTATS is a Salesforce-based application designed to track, manage, and analyze cricket player performance on a match-by-match basis.

## Purpose
The purpose of this project is to provide a centralized platform for managing player information and match performance statistics using Salesforce.

## Target Users
- Team Managers
- Coaches
- Cricket Analysts
- Salesforce Administrators

## Selected Idea
A Salesforce-based Cricket Player Performance Tracking Platform was selected to manage player details, match performance, statistics, reports, dashboards, and automation.

## Main Features
- Player Registration
- Match Performance Entry
- Player Statistics
- Reports and Dashboards
- Flow Automation
- Performance Analysis
